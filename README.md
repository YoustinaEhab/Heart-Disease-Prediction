# Heart Disease Prediction Using Machine Learning

## Overview
A machine learning project that predicts heart disease using 16 clinical attributes. The project applies data preprocessing, feature selection, and classification algorithms to analyze patient data and evaluate predictive performance.

## Features
- Data cleaning and preprocessing
- Missing-value handling and categorical encoding
- Outlier detection and feature scaling
- Feature analysis using correlation and Chi-squared tests
- Training and evaluation of three machine learning classifiers

## Technologies Used
- **Python**
- **Pandas & NumPy** — Data manipulation
- **Scikit-learn** — Preprocessing, model training, and evaluation
- **Matplotlib & Seaborn** — Data visualization
- **SciPy** — Statistical analysis

## Machine Learning Models
1. Logistic Regression
2. Support Vector Machine (SVM)
3. Decision Tree Classifier

## Workflow
1. Load and explore the dataset.
2. Clean and preprocess the data.
3. Analyze features using correlation and Chi-squared tests.
4. Split the dataset into training (80%) and testing (20%) sets.
5. Train and compare the three classification models.
6. Evaluate performance using accuracy, confusion matrices, precision, recall, F1-score, and classification reports.

## Results
The project achieved a reported **92% accuracy**. The performance of each classifier can be compared using the evaluation metrics.
